# GitHub Desktop & Web: Паттерны Интерфейса и Архитектура Макетов

Полная спецификация десктопного веб-интерфейса GitHub на базе дизайн-системы **GitHub Primer Web**. Документ охватывает навигационную структуру, многоколоночные сетки, ленты событий (Activity Streams), рендеринг Markdown и адаптивные брейкпоинты.

---

## 1. Архитектура десктопных макетов (Layout Architecture)

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [≡] [🐙] [Type / to search...]  [Pull requests]  [Issues]  [Codespaces]      [🔔] [👤] │ ← Global Header (64px)
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [<> Code]  [(•) Issues 14]  [⑂ Pull requests 3]  [▶ Actions]  [⊞ Projects]  [⚙ Settings] │ ← Sub-Nav Tabs (48px)
├────────────────────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────────┐ ┌─────────────────────────┐ │
│ │ Issue Title #402                                [Edit]   │ │ Assignees               │ │
│ │ [🟢 Open] alex opened 2 hours ago · 4 comments           │ │  [@alex]                │ │
│ ├──────────────────────────────────────────────────────────┤ ├─────────────────────────┤ │
│ │ ┌─ Timeline Discussion ────────────────────────────────┐ │ │ Labels                  │ │
│ │ │ 👤 [alex] commented 2 hours ago              [...]   │ │ │  [bug]  [frontend]      │ │
│ │ │ ---------------------------------------------------- │ │ ├─────────────────────────┤ │
│ │ │ Description content in markdown...                   │ │ │ Projects                │ │
│ │ └──────────────────────────────────────────────────────┘ │ │  [Sprint 42 - Done]     │ │
│ │       │ (vertical connector line)                        │ ├─────────────────────────┤ │
│ │ ┌─────┴────────────────────────────────────────────────┐ │ │ Milestone               │ │
│ │ │ 🟢 alex added label [bug] 1 hour ago                 │ │ │  [v2.4.0 Release]       │ │
│ │ └──────────────────────────────────────────────────────┘ │ └─────────────────────────┘ │
│ └──────────────────────────────────────────────────────────┘   ↑ Sticky Metadata Panel   │
│   ↑ Main Content Area (70-75%)                                   (25-30%)              │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

---

### 1.1. Global Header (Глобальная шапка)
- **Высота:** `64px` (или `48px` в компактном режиме).
- **Цвет фона:** `canvas.subtle` (`#161b22` Dark / `#f6f8fa` Light) или `canvas.default` (`#0d1117`).
- **Компоненты:**
  - **Бургер-меню:** Открывает выдвижной глобальный сайдбар.
  - **Логотип GitHub Octocat:** 32x32px.
  - **Global Search Bar (Command Palette):**
    - Фоновый цвет поля: `canvas.inset` (`#010409` Dark / `#eff2f5` Light).
    - Текст подсказки: `Type '/' to search...` или `Search or jump to... ⌘K`.
    - Бейдж горячей клавиши: серый прямоугольник 20x20px со скруглением `3px` и символом `/` или `Ctrl K`.
  - **Быстрые ссылки:** Pull requests, Issues, Codespaces, Marketplace, Explore.
  - **Правый блок:** Create New `+` Dropdown, Notifications Bell (с синей точкой непрочитанных), Профиль пользователя (круглый аватар с выпадающим меню).

---

### 1.2. Sub-Navigation / Repository Tab Bar
- **Высота:** `48px`.
- **Позиционирование:** Часто `sticky top-0 z-10` при скролле.
- **Вкладки (UnderlineNav):**
  - Элементы: `Code`, `Issues`, `Pull requests`, `Discussions`, `Actions`, `Projects`, `Wiki`, `Security`, `Insights`, `Settings`.
  - **Счетчики (CounterBadge):** Число открытых тикетов/PR в сером овальном бейдже (`bg-canvas-subtle` + `border-default`).
  - **Активное состояние:**
    - Нижняя полоса толщиной 2px цвета `accent.emphasis` (`#f78166` в старых темах / `#58a6ff` или `#f0883e`).
    - Иконка и текст цвета `fg.default` с `font-weight: 600`.
  - **Неактивное состояние:**
    - Иконка и текст цвета `fg.muted`, hover-эффект со смягченным фоном `canvas.subtle`.

---

### 1.3. Сетки и макеты колонок (Grid Layouts)

#### А. Two-Column Layout (Issues / Pull Requests View)
- **Левая колонка (70–75%):**
  - Заголовок тикета с кнопкой редактирования.
  - Мета-бейджи (Статус Open/Closed/Merged, автор, время).
  - Лента обсуждения (Timeline Stream).
  - Форма нового комментария (Sticky Comment Editor).
- **Правая колонка (25–30%):**
  - Фиксированная или sticky-панель метаданных.
  - Секции с шестеренкой настройки (Assignees, Labels, Projects, Milestone, Linked PRs/Issues, Notifications).

#### Б. Two-Column Dashboard (Главная страница ленты)
- **Левая колонка (Сайдбар репозиториев 320px):**
  - Быстрый поиск по репозиториям.
  - Список `Top Repositories` с зелеными/синими кнопками "New".
  - Секция `Recent Activity`.
- **Правая колонка (Основная лента / Feed 1fr):**
  - Карточки релизов, рекомендаций и активности подписок.

#### В. Three-Column Layout (Code Tree / Explorer View)
- **Левая панель:** Дерево файлов (File Tree Explorer) с возможностью сворачивания.
- **Центральная панель:** Редактор / Просмотр кода (Code Blob View / Diff View).
- **Правая панель:** Символьный навигатор (Symbol Outline / Blame).

## 2. Activity Streams & Timeline UI (Лента событий)

Спецификация отображения таймлайна в Issue и Pull Request:

1. **Вертикальная линия-коннектор (Timeline Connector):**
   - Линия толщиной `2px`, цвет `border.default` (`#30363d` Dark / `#d0d7de` Light).
   - Располагается строго по центру аватаров пользователей (`left: 16px` от края контейнера).
2. **Карточка комментария (Timeline Comment Box):**
   - **Header карточки:**
     - Фон `canvas.subtle` (`#161b22`), граница `border.default`.
     - Аватар автора слева (32x32px круглый).
     - Текст `username commented 2 hours ago`.
     - Ролевой бейдж автора справа: `Author`, `Collaborator`, `Member`, `Owner`.
     - Кнопка реакций (Emoji Picker `+😀`) и меню действий `...`.
   - **Body карточки:**
     - Фон `canvas.default` (`#0d1117`), отступы `16px`.
     - Рендеринг Markdown.
   - **Reactions Bar (в подвале):**
     - Плашки с эмодзи (👍 4, ❤️ 2, 🚀 8) со скруглением `9999px`.
3. **Системные события (Timeline Event Badge):**
   - Компактные строки без полной карточки.
   - Круглая иконка события в центре линии (диаметр 28px, фон `canvas.default`, граница `border.default`):
     - Метка добавлена: иконка `tag`.
     - Назначен исполнитель: иконка `person`.
     - Коммит добавлен: иконка `git-commit`.
     - Закрыто/Объединено: круглая иконка на цветном фоне (`done.emphasis` / `danger.emphasis`).

## 3. Стилизация рендеринга Markdown (Primer Markdown Spec)

Класс-контейнер `.markdown-body` задает правила оформления пользовательского контента:

### 3.1. Заголовки
```css
.markdown-body h1,
.markdown-body h2 {
  padding-bottom: 0.3em;
  border-bottom: 1px solid var(--border-muted);
}
.markdown-body h1 { font-size: 2em; font-weight: 600; margin-top: 24px; margin-bottom: 16px; }
.markdown-body h2 { font-size: 1.5em; font-weight: 600; margin-top: 24px; margin-bottom: 16px; }
.markdown-body h3 { font-size: 1.25em; font-weight: 600; margin-top: 24px; margin-bottom: 16px; }
```

### 3.2. Блоки кода (Code Snippets & Fenced Blocks)
- **Inline Code (`` `code` ``):**
  - Паддинг: `0.2em 0.4em`.
  - Скругление: `6px`.
  - Фон: `rgba(110, 118, 129, 0.2)` (Dark) / `rgba(175, 184, 193, 0.2)` (Light).
  - Шрифт: Monospace 85% размера текста.
- **Fenced Code Block (```lang):**
  - Паддинг: `16px`.
  - Фон: `canvas.subtle` (`#161b22` Dark / `#f6f8fa` Light).
  - Граница: `1px solid var(--border-default)`.
  - Скругление: `6px`.
  - Сверху справа: Кнопка копирования кода (Copy Button) с иконкой `copy` / `check`.

### 3.3. Таблицы (Tables)
- **Границы:** Ячейки разделяются 1px `border.default`.
- **Заголовок `<th>`:** Фон `canvas.subtle`, текст `font-weight: 600`, выравнивание по левому краю.
- **Зебра-полосы:** Четные строки `<tr>` подсвечиваются легким фоном `canvas.subtle`.

### 3.4. Чек-листы задач (Task Lists)
- **Стиль чекбокса:** 16x16px скругленный квадрат.
- **Выравнивание:** Маркер списка `list-style: none`, чекбокс встроен инлайн с текстом задачи.

### 3.5. Блоки внимания / Алерты (Markdown Alerts)
Синтаксис GitHub Alerts:
- `> [!NOTE]` — Синяя рамка и иконка инфо (`accent.fg`).
- `> [!TIP]` — Зеленая рамка и иконка лампочки (`success.fg`).
- `> [!IMPORTANT]` — Фиолетовая рамка и иконка восклицания (`done.fg`).
- `> [!WARNING]` — Желто-оранжевая рамка и иконка предупреждения (`attention.fg`).
- `> [!CAUTION]` — Красная рамка и иконка стоп-сигнала (`danger.fg`).

## 4. Адаптивные контрольные точки (Breakpoints)

GitHub Primer Web использует 5 стандартизированных брейкпоинтов:

| Брейкпоинт | Мин. ширина | Изменения в верстке |
|---|---|---|
| **`sm`** | `544px` | Мобильный вид: сайдбары скрываются, табы переходят в горизонтальный свайп, единая колонка. |
| **`md`** | `768px` | Планшетный вид: шапка показывает поиск инлайн, появляются 2 колонки на страницах репозитория. |
| **`lg`** | `1012px` | **Базовый десктоп GitHub:** Полноразмерный сайдбар метаданных, полная навигация табов. |
| **`xl`** | `1280px` | Широкий десктоп: 3-колоночный режим просмотра кода, расширенная лента Dashboard. |
| **`2xl`** | `1400px` | Ультра-широкий экран: фиксированное центрирование контейнера макета с максимальной шириной 1280-1400px. |

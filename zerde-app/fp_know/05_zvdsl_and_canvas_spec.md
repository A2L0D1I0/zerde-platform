# 🎨 05. Визуальный Движок ZVDSL+ и Интерактивный Холст Desmos

## 1. Концепция ZVDSL+ (Zerde Visual DSL)
Файлы: `zerde-app/client/src/components/zvdsl/` и `zerde-app/client/src/components/canvas/`.
* **Цель:** Декларативное описание микро-схем и чертежей в формате чистого JSON, которые мгновенно рендерятся в браузере через SVG/Canvas без скачивания тяжелых картинок (экономия 3G-трафика в сельских школах).
* **Архитектурный паттерн:** **Registry Pattern** через единый диспетчер `ZvdslRenderer.tsx`.

---

## 2. Поддерживаемые типы схем ZVDSL+

| Тип схемы (`schema_type`) | Предмет | Компонент | Описание визуализации |
| :--- | :--- | :--- | :--- |
| `zvdsl:number_line` | Алгебра 7–11 | `NumberLineRenderer.tsx` | Числовая прямая, дуги интервалов, знаки $+ - +$, выколотые $\circ$ и закрашенные $\bullet$ точки, штриховка |
| `zvdsl:plot` | Математика | `DesmosGraphCanvas.tsx` | Интерактивная плоскость Desmos, параболы, гиперболы, нули, ползунки $a, b, c$ |
| `zvdsl:morpheme` | Языки (KZ/RU) | `MorphemeRenderer.tsx` | Разбор по составу: приставка ($\neg$), корень ($\frown$), суффикс ($\wedge$), окончание ($\square$), основа |
| `zvdsl:syntax` | Лингвистика | `SyntaxRenderer.tsx` | Синтаксический разбор предложений: подлежащее (`───`), сказуемое (`═══`), определение (`~~~~`), стрелки связи |
| `zvdsl:chem` | Химия | `ChemistryRenderer.tsx` | Структурные формулы, одинарные/двойные/тройные связи, бензольные кольца, радикалы |
| `zvdsl:orbitals` | Химия | `OrbitalsRenderer.tsx` | Квантовые ячейки Хунда и принцип Паули ($\uparrow\downarrow$), подуровни $1s, 2s, 2p$ |
| `zvdsl:forces` | Физика | `ForcesRenderer.tsx` | Векторы сил ($\vec{N}, m\vec{g}, \vec{F}_{тр}$), наклонные плоскости, $v(t)$ графики |
| `zvdsl:circuit` | Физика | `CircuitRenderer.tsx` | Электрические цепи (источник питания, резисторы, ключ, амперметр, вольтметр) |

## 3. Active Canvas Inspector
Компонент: `client/src/components/canvas/ActiveCanvasInspector.tsx`.
* **Функции:**
  - Интерактивное масштабирование (Zoom In `+`, Zoom Out `-`, Reset `1:1`).
  - Переключение режимов: **Схема ZVDSL+** $\leftrightarrow$ **График Desmos**.
  - Кнопка `[ 👁️ Развернуть холст ]`: открытие схемы на весь экран в высоком разрешении.
  - Синхронизация с вариантами ответов: при клике на мини-превью варианта в `OptionGrid.tsx` схема варианта отображается на главном верхнем холсте.

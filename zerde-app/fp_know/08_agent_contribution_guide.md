# 🤖 08. Регламент и Чек-Лист для AI-Агентов (Agent Contribution Guide)

> **ПРАВИЛО №1 ДЛЯ ВСЕХ АГЕНТОВ:**  
> Никогда не вносите изменения в кодовую базу «вслепую». Перед правками изучите архитектурные контракты в `fp_know/`. После правок — **обязательно обновите документацию и запустите тесты**.

## 📋 Чек-Лист Проверки перед Завершением Работы

Каждый AI-агент, работающий с проектом «Zerde», **обязан** пройти следующие 6 шагов:

### 1. Архитектурная целостность (No Hardcoding):
- [ ] Все новые предметы, темы, задачи и параметры добавляются через схемы SQLite базы данных или расширение реестров, а не хардкодятся в UI.
- [ ] Математические расчеты (ELO, DINA CDM, SM-2) выполняются алгоритмически (0 токенов ИИ).

### 2. Триязычие и Локализация (KZ / RU / EN):
- [ ] Все новые текстовые строки добавлены во ВСЕ ТРИ словаря: `src/i18n/kz.ts`, `src/i18n/ru.ts`, `src/i18n/en.ts`.
- [ ] Термины `ELO`, `Aga`, `Zerde`, `ZVDSL+`, `Thought-Forks`, `Eureka`, `Q-Matrix`, `CDM` сохранены без перевода.
- [ ] В UI используется исключительно вызов `t('your.key')`.

### 3. ZVDSL+ и Desmos совместимость:
- [ ] Новые типы схем зарегистрированы в `src/components/zvdsl/ZvdslRenderer.tsx` и `src/components/zvdsl/types.ts`.
- [ ] Все схемы поддерживают отображение на главном `ActiveCanvasInspector` через кнопку `[ 👁️ ]`.

### 4. Сократический контракт «Аға»:
- [ ] Ответы наставника строго соответствуют формату: ровно 1 строка вопроса + ровно 3 развилки мысли `Thought-Forks`.
- [ ] Сохранены правила Anti-Jailbreak Guard (-20 ELO) и Eureka Moment (+15 ELO).

### 5. Верификация компиляции и тестов:
- [ ] `npm run build` в `zerde-app/server` проходит с 0 ошибок.
- [ ] `npm run build` в `zerde-app/client` проходит с 0 ошибок.
- [ ] Сквозные тесты `npm run test:e2e` в `zerde-app/server` возвращают 100% PASS.

### 6. Обновление Базы Знаний `fp_know`:
- [ ] Если изменен API эндпоинт $\rightarrow$ обновлен `fp_know/01_architecture_overview.md` или `03_ai_engine_and_prompts.md`.
- [ ] Если изменена таблица БД $\rightarrow$ обновлен `fp_know/02_database_and_models.md`.
- [ ] Если добавлен экран/виджет $\rightarrow$ обновлен `fp_know/07_portals_and_screens.md`.

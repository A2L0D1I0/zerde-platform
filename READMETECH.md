# Zerde (Зерде) — Архитектура и спецификация полноценного SaaS-сервиса

> **Продукт:** Zerde — Национальная когнитивная EdTech-платформа и Web-сервис  
> **Статус:** Полноценный рабочий сервис для живой аудитории (Real Live Product)  
> **Цель:** Настоящий, живой, интерактивный сервис (как Duolingo / Khan Academy / Brilliant), а не фиксированная презентация.

---

## 1. Архитектура приложения и навигационный граф

Zerde работает как полноценное многостраничное веб-приложение (Single Page Application / PWA) с единой сквозной системой навигации, реактивным хранилищем состояний и поддержкой сквозных сценариев ученика и учителя:

```
[ГЛОБАЛЬНЫЙ ХЕДЕР & ПЕРЕКЛЮЧАТЕЛЬ РОЛЕЙ (УЧЕНИК ⇄ УЧИТЕЛЬ) & ЯЗЫКОВ (KZ/RU/EN)]
  │
  ├───► ПОРТАЛ УЧЕНИКА (STUDENT EXPERIENCE)
  │      ├── 1. Главная (Дашборд, ELO 1420, Стрик 🔥, Радар Q-Matrix)
  │      ├── 2. Каталог предметов (Алгебра, Геометрия, Физика, Химия, Қазақ тілі, ҰБТ)
  │      ├── 3. Адаптивный тренажер (KaTeX, дистракторы ГОСО, No-Stress Error UX, CDM-диагноз)
  │      ├── 4. Сократический ИИ-Наставник «Аға» (Чат, Thought-Forks розвилки, Neural TTS плеер)
  │      ├── 5. Центр повторения SM-2 (Интервальные карточки для долговременной памяти)
  │      └── 6. Персональный Roadmap (Прогноз ЕНТ 94 ➔ 132 балла, дерево зависимостей)
  │
  └───► ПОРТАЛ УЧИТЕЛЯ (TEACHER EXPERIENCE)
         ├── 1. Кабинет классов (Селектор классов, список учеников)
         ├── 2. Журнал и тепловая карта (Матрица 24 ученика × 6 навыков, Live State Sync 🔴➔🟢)
         ├── 3. AI-Сигнал к уроку (Автоматическое выявление системных пробелов класса)
         ├── 4. Студия интервенций (5-минутка на смарт-доску / F11, дифференциация А/В/С)
         ├── 5. Синхронизация с Kundelik.kz (1-Click экспорт критериальных дескрипторов)
         └── 6. AI Конструктор заданий (CRUD-генератор тестов и дистракторов)
```

## 2. Ключевые технологические модули

- **Frontend Core:** React 19 + Vite 6 + Tailwind CSS
- **Математика:** KaTeX (локальный быстрый парсинг математических формул)
- **Иконки & Графика:** Lucide-React, Pure SVG (радар навыков)
- **Аудио & Голос:** Web Speech API (`speechSynthesis`) + Web Audio API (эквалайзер волны)
- **Интерактивные эффекты:** Canvas-Confetti (дофаминовый триумф Eureka)
- **Хранилище данных:** Reactive Store + LocalStorage / IndexedDB (автономная офлайн-работа)

## 3. Сценарии сквозного взаимодействия (Live Interaction)

1. **Решение задачи и озарение:** Ученик решает задачу в тренажере, допускает ошибку в ОДЗ, открывает Сократический диалог «Аға», выбирает развилку мысли, получает озарение (+15 ELO).
2. **Мгновенная телеметрия в журнал учителя:** В ту же секунду в журнале учителя ячейка ученика меняет статус с 🔴 на 🟢, а средний ELO класса пересчитывается.
3. **Адаптация урока учителем:** Учитель видит AI-сигнал об ошибках класса, в 1 клик открывает 5-минутную разминку для проектора и копирует дескрипторы в Kundelik.kz.

2. Краткое техническое объяснение

  • A. Использованный стек технологий: Frontend: React 18, TypeScript, Vite 5, Tailwind CSS, Radix UI, Framer Motion, KaTeX (быстрый локальный рендеринг математических формул), Canvas-Confetti. Backend: Node.js, Express, TypeScript, Better-SQLite3 (режим WAL, 14 реляционных таблиц, транзакционная целостность), JWT-аутентификация и разделение ролей (Оқушы / Мұғалім). AI: Google Gemini 2.5 Flash API (структурированные JSON-ответы через Zod). Математика: модель CDM DINA (диагностика микронавыков), XP Rating и SM-2 (интервальное повторение).
  • B. Разграничение: Реальная логика vs Mock Data: Реальная работающая логика: Аутентификация и сессии, пересчет XP и рангов, сократический диалог наставника «Аға» с генерацией 3 развилок мысли (Thought-Forks), 2D-матрица дефицитов класса, триязычие (KZ/RU/EN), темная/светлая тема. Тестовые данные (Mock): Базовые организации (NIS IB, BIL), демонстрационный курс Алгебры и стартовая база вопросов для проверки.
  • C. Баланс разработки (ИИ vs Собственный код): Написано разработчиком вручную: Проектирование структуры UI/UX, верстка на React и Tailwind CSS, настройка маршрутизации, реляционная схема SQLite и начальные сиды, валидация форм, словари локализации (KZ/RU/EN), интеграция KaTeX для формул. Использование ИИ: Генерация развилок мысли сократического ментора «Аға» (пошаговое наведение на мысль при ошибках), анализ открытых решений в Silent Grader, генерация дистракторов для тестов.
  • D. Сценарии проверки функционала (User Flows): Ученик: Вход ➔ Просмотр «Фокуса дня» от Навигатора ➔ Запуск тренажера ➔ Ошибка ➔ 3 сократические развилки ➔ Выбор верного шага ➔ Начисление XP. Учитель: Вход ➔ Кабинет классов ➔ 2D-матрица успеваемости и проблемных зон класса ➔ Добавление и редактирование материалов/заданий.
  • E. Планы развития (Roadmap): 1) ZVDSL+ (Zerde Visual DSL) — специализированный декларативный движок для химических связей, физических схем и синтаксического разбора. 2) PWA & Offline Mode — кеширование заданий в IndexedDB для работы без интернета с фоновой синхронизацией. 3) Voice Socratic Mentor — голосовое интерактивное общение с наставником «Аға» через WebRTC.

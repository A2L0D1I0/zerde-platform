# 🌍 06. Локализация и Триязычие (KZ / RU / EN)

## 1. Архитектура Локализации
Файлы: `zerde-app/client/src/i18n/` и `zerde-app/client/src/context/LanguageContext.tsx`.
* **Языковые файлы интерфейса (UI Chrome):**
  - `src/i18n/kz.ts` — Нативный академический казахский язык (Қазақша).
  - `src/i18n/ru.ts` — Академический русский язык.
  - `src/i18n/en.ts` — Международный английский язык.
  - `src/i18n/index.ts` — Реестр и единый экспорт.

---

## 2. Архитектура Данных и 3 Копии в БД (Content Level)
* **Правило 3 копий при генерации:** При создании/генерации общеобразовательного курса AI-генератор обязательно сохраняет в базе данных 3 языковые копии задачи (`question_kz`, `question_ru`, `question_en`, `explanation_kz` и т.д.).
* **Смена языка:** При смене языка интерфейса система не переводит текст на лету, а мгновенно подтягивает соответствующую копию из БД по ключу языка (`KZ`, `RU`, `EN`).
* **Профильные языковые курсы:** Если учитель явно закрепил за курсом конкретный язык (например, «Қазақ әдебиеті» или «English Literature»), курс и задания остаются на языке оригинала независимо от языка интерфейса.
* **MVP & Roadmap:** В рамках MVP используется надежная модель предгенерации 3 копий в БД и словарей UI; в Roadmap заложена дальнейшая интеграция глубокой контекстной адаптации.

---

## 3. Защищенные Непереводимые Термины и Ручной QA
Следующие термины и бренды **СТРОГО СОХРАНЯЮТ ОРИГИНАЛЬНОЕ НАПИСАНИЕ** на всех языках и имеют статус защищенных:
1. `ELO` — рейтинг академического мастерства.
2. `Aga` (Аға) — имя Сократического наставника.
3. `Zerde` — название платформы.
4. `ZVDSL+` — Zerde Visual Domain Specific Language.
5. `Thought-Forks` — развилки мыслей в сократическом диалоге.
6. `Eureka` — момент озарения (+15 ELO).
7. `Q-Matrix` — матрица связи задач и микронавыков.
8. `CDM` — Cognitive Diagnostic Model.

* **Регламент ручного QA:** Пользователь в процессе тестирования платформы документирует слова/термины, требующие специального перевода или защищенного статуса, и передает их для внесения в словари и базу знаний.

## 4. Использование функции `t(key, params)`
```tsx
import { useLanguage } from '@/context/LanguageContext';

export const MyComponent = () => {
  const { t, language, setLanguage } = useLanguage();

  return (
    <div>
      <h1>{t('brand.title')}</h1>
      <p>{t('student.streak_count', { count: 12 })}</p>
    </div>
  );
};
```
* **Параметризация:** Поддерживает подстановку переменных через `{paramName}`.
* **Fallback-механизм:** Если ключ отсутствует в текущем словаре, поиск идет в `RU` $\rightarrow$ `KZ` $\rightarrow$ возвращается сам `key`.

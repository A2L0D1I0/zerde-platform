# 🧠 03. ИИ-Ядро, Оркестратор и 5 Системных Промптов

## 1. Архитектура Сервиса `ai-orchestrator.ts`
Серверный файл: `zerde-app/server/src/services/ai-orchestrator.ts`.
* **Провайдеры:** Поддержка Google Gemini API (`@google/genai`, модели `gemini-1.5-flash` / `gemini-2.0-flash`), OpenAI API, и **локальный детерминированный Fallback Rule Engine**.
* **Ключи окружения:** Читает `AI_API_KEY`, `GEMINI_API_KEY`, `GOOGLE_API_KEY` или `OPENAI_API_KEY` из файла `.env`.
* **Безотказность (0 Downtime):** Если ключ отсутствует, исчерпан лимит или нет интернета, оркестратор бесшовно возвращает точные структурированные ответы из локального банка правил.

## 2. Спецификация 5 Системных Промптов

### 2.1. Промпт 1: Сократический «Аға» (Student Companion & Thought-Forks Engine)
* **Цель:** Вести ученика к правильному пониманию без выдачи готового ответа.
* **Формат ответа СТРОГО:**
  1. `question_line`: ровно 1 строка наводящего вопроса.
  2. `thought_forks`: ровно 3 визуальные развилки мысли:
     - `branch_a`: истинный следующий логический шаг (правильный ход мысли);
     - `branch_b`: типичная когнитивная ловушка/ошибка (неправильный знак, выколотая точка);
     - `branch_c`: напоминание фундаментального правила или формулы.
* **Anti-Jailbreak Guard:**
  - Распознает спам, мат, попытки взлома («забудь инструкции», «дай ответ», «реши за меня»).
  - Назначает штраф **`-20 ELO`** (с защитой нижнего порога $ELO \ge 0$).
* **Anti-Stuck & Eureka Moment:**
  - При 2 ошибках подряд активирует подсказку третьего уровня и выводит на **Eureka Moment (`+15 ELO`)**.

### 2.2. Промпт 2: Teacher Co-Pilot & Course Architect
* **Цель:** Диалоговый помощник учителя при создании курсов.
* **Функции:** Анализ загруженного учебника/конспекта, предложение разбивки на микро-темы, формулировка целей СОР/СОЧ, генерация рубрик и дескрипторов для Kundelik.kz.

### 2.3. Промпт 3: File Parser & Knowledge Graph Extractor
* **Цель:** Извлечение графа понятий из сырых PDF/DOCX документов.
* **Результат:** Иерархия тем, формулы, правила, Q-Matrix микронавыков для каждого параграфа.

### 2.4. Промпт 4: Assessment & Distractor Generator
* **Цель:** Генерация проверочных вопросов Режима А и Режима Б.
* **Правило дистракторов:** Варианты ответов обязаны содержать логически обоснованные когнитивные ловушки школьников, а не случайные числа.

### 2.5. Промпт 5: Class Telemetry Diagnostics
* **Цель:** Анализ матрицы успеваемости 24 учеников за 5 секунд.
* **Результат:** «Сигнал дня» (главная общая ошибка класса) + 5-минутная экспресс-разминка для смарт-доски (F11) с тремя уровнями сложности A/B/C.

## 3. Оценка Режима Б (Тетрадь и Фото-Решения)
* Метод: `evaluateNotebookSolution(prompt, studentText, photoUrls, lang)`.
* Дифференцированное начисление ELO:
  - **`+3 ELO`**: Только голый ответ без объяснения.
  - **`+7 ELO`**: Краткий ход мысли с промежуточным шагом.
  - **`+15 ELO` (Eureka 🎉)**: Полное пошаговое математическое/логическое обоснование.
  - **`-20 ELO`**: Попытка жульничества или нерелевантный текст.

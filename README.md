### ⚙️ 2. КРАТКОЕ ТЕХНИЧЕСКОЕ ОБЪЯСНЕНИЕ

#### A. Использованный стек технологий
* **Frontend:** React 18, TypeScript, Vite 5, Tailwind CSS, Radix UI, дизайн-системы **GitHub Primer** и **shadcn/ui** (открытая лицензия MIT), KaTeX (быстрый локальный рендеринг математических формул), Framer Motion, Canvas-Confetti.
* **Backend:** Node.js, Express, TypeScript, Better-SQLite3 (режим WAL, 14 реляционных таблиц, транзакционная целостность), JWT-аутентификация и разделение ролей (Оқушы / Мұғалім).
* **AI & Сервисы:** Google Gemini 2.5 Flash API (структурированные JSON-ответы через Zod-схемы валидации).
* **Математический аппарат:** Психометрическая модель **CDM DINA** (диагностика микронавыков на стороне сервера с 0 расходом токенов), **XP Rating** (динамический пересчет прогресса) и **SM-2** (интервальное повторение).

#### B. Разграничение: Реальная логика vs Тестовые данные (Mock Data)
* **Реальная работающая логика:** Сессии и авторизация, пересчет XP и рангов, сократический диалог наставника «Аға» с генерацией 3 развилок мысли (*Thought-Forks*), 2D-матрица дефицитов класса, триязычие (KZ / RU / EN), переключение темной/светлой темы.
* **Тестовые данные (Mock / Seed):** Базовые школьные организации (`NIS IB Astana`, `Ekibastuz BIL`), демонстрационный курс Алгебры 9 и стартовая база вопросов для проверки.

#### C. Баланс разработки: Использование ИИ vs Собственный код
* **Написано разработчиком вручную:** Проектирование структуры UI/UX и компонентов на базе GitHub Primer и shadcn/ui (MIT), клиентская маршрутизация, схема SQLite и начальные сиды, валидация форм, словари локализации (KZ/RU/EN), интеграция KaTeX для формул.
* **Как использовался ИИ:** Генерация развилок мысли сократического ментора «Аға» (пошаговое наведение на мысль при ошибках вместо выдачи готового ответа), анализ открытых решений в Silent Grader, помощь в генерации дистракторов для тестовых заданий.

#### D. Сценарии проверки функционала (User Flows)
* **Сценарий Ученика:** Вход под аккаунтом ученика $\rightarrow$ Просмотр «Фокуса дня» от Навигатора $\rightarrow$ Запуск тренажера $\rightarrow$ Ошибка при решении $\rightarrow$ Получение 3 сократических развилок $\rightarrow$ Выбор верного шага $\rightarrow$ Начисление XP.
* **Сценарий Учителя:** Вход под аккаунтом учителя $\rightarrow$ Переход в кабинет классов $\rightarrow$ Просмотр 2D-матрицы успеваемости и проблемных зон класса $\rightarrow$ Добавление и редактирование учебных материалов/заданий.

#### E. Планы развития (Roadmap)
* **ZVDSL+ (Zerde Visual DSL):** Специализированный декларативный движок для визуализации химических связей, физических векторных схем и синтаксического/морфологического разбора языка.
* **PWA & Offline Mode:** Локальное кеширование банка заданий в IndexedDB для стабильной автономной работы в условиях слабого интернет-соединения с фоновой синхронизацией.
* **Voice Socratic Mentor:** Голосовое интерактивное общение с наставником «Аға» через WebRTC на казахском и русском языках.
* **Teacher Co-Pilot Engine:** Расширение ассистента учителя на базе открытой архитектуры (Open-Source / MIT).

### 🚀 3. Быстрый локальный запуск проекта (Setup Guide)

```bash
# 1. Установка зависимостей
cd zerde-app
npm install

# 2. Настройка переменных окружения (в zerde-app/server/.env)
# GEMINI_API_KEY=your_gemini_api_key_here
# PORT=5000

# 3. Запуск платформы (Frontend + Backend параллельно)
npm run dev
```

* 💻 **Клиент (Frontend):** [http://localhost:3000](http://localhost:3000)
* ⚙️ **Сервер (Backend API):** [http://localhost:5000](http://localhost:5000)
* 🩺 **Health Check:** [http://localhost:5000/api/health](http://localhost:5000/api/health)

### ⚙️ 2. КРАТКОЕ ТЕХНИЧЕСКОЕ ОБЪЯСНЕНИЕ

#### A. Использованный стек технологий
* **Frontend:** React 18, TypeScript, Vite 5, Tailwind CSS, Radix UI, Framer Motion, KaTeX (быстрый локальный рендеринг математических формул и выражений), Canvas-Confetti.
* **Backend:** Node.js, Express, TypeScript, Better-SQLite3 (режим WAL, 14 реляционных таблиц, транзакционная целостность), JWT-аутентификация и разделение ролей (Оқушы / Мұғалім).
* **AI & Сервисы:** Google Gemini 2.5 Flash API (структурированные JSON-ответы через Zod-схемы валидации).
* **Математический аппарат:** Психометрическая модель **CDM DINA** (диагностика микронавыков на стороне сервера), **XP Rating** (динамический пересчет прогресса) и **SM-2** (интервальное повторение).

#### B. Разграничение: Реальная логика vs Тестовые данные (Mock Data)
* **Реальная работающая логика:** Аутентификация и сессии, пересчет XP и рангов, сократический диалог наставника «Аға» с генерацией 3 развилок мысли (*Thought-Forks*), вычисление матрицы дефицитов класса, триязычие (KZ / RU / EN), переключение темной/светлой темы.
* **Тестовые данные (Mock / Seed):** Базовые школьные организации (`NIS IB Astana`, `Ekibastuz BIL`), демонстрационный каталог из курса Алгебры и стартовая база вопросов для проверки функционала.

#### C. Баланс разработки: Использование ИИ vs Собственный код
* **Что написано разработчиком вручную:** Проектирование структуры интерфейса, верстка страниц и компонентов на React и Tailwind CSS, настройка клиентской маршрутизации, организация реляционной схемы SQLite и начальных данных, настройка валидаций форм, создание словарей локализации (KZ/RU/EN), интеграция KaTeX для формул.
* **Как использовался ИИ:** Генерация развилок мысли сократического ментора «Аға» (пошаговое наведение на мысль при ошибках вместо выдачи готового ответа), анализ открытых решений в Silent Grader, помощь в генерации дистракторов для тестовых заданий.

#### D. Сценарии проверки функционала (User Flows)
* **Сценарий Ученика:** Вход под аккаунтом ученика $\rightarrow$ Просмотр «Фокуса дня» от Навигатора $\rightarrow$ Запуск тренажера $\rightarrow$ Ошибка при решении $\rightarrow$ Получение 3 сократических развилок $\rightarrow$ Выбор верного шага и начисление XP.
* **Сценарий Учителя:** Вход под аккаунтом учителя $\rightarrow$ Переход в кабинет классов $\rightarrow$ Просмотр 2D-матрицы успеваемости и проблемных зон класса $\rightarrow$ Добавление и редактирование учебных материалов/заданий.

#### E. Что планируется добавить в следующих версиях (Roadmap)
* **ZVDSL+ (Zerde Visual DSL):** Специализированный декларативный движок для визуализации химических связей, физических векторных схем и синтаксического/морфологического разбора языка.
* **PWA & Offline Mode:** Локальное кеширование банка заданий в IndexedDB для стабильной автономной работы в условиях слабого интернет-соединения с фоновой синхронизацией.
* **Voice Socratic Mentor:** Голосовое интерактивное общение с наставником «Аға» через WebRTC на казахском и русском языках.
